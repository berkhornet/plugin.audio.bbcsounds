plugin.audio.bbcsounds
======================

A plug-in for the [Kodi media center](https://kodi.tv) that unlocks the
wonderful world of BBC Sounds for Kodi users.

This is an unofficial plug-in, not created or endorsed by the BBC.

The plugin is currently in the beta stage. The addon should now be in a 
decent enough state to be tested by a wider audience.


## Installation
Only Kodi 21 (Omega) or newer are actively supported. Kodi 19 (Matrix) and older
will definitely not work.

While in beta stage, the addon can only be installed as zip 
file. Download the zip from the 
[releases](https://github.com/dimkroon/plugin.audio.bbcsounds/releases) section 
of this repo, or visit 
[dimkroon.net](https://dimkroon.net/en/pages/addon-bbcsounds.html) for more 
details and installation instructions.


## Usage

The best way to explore is simply to browse through the add-on to see 
what is available. An important part of the functionality is available through 
an item's context menu, depending on the item and where it is listed. 

### Features

- Live radio
  - National and regional stations.
  - All local stations that are available on the BBC Sounds website.
  - 'Listen from the start' (Omega only)
- All podcasts on the BBC Sounds website.
- All previous radio programmes available on the BBC Sounds website.
- Subscribe and bookmark items.
- Context menu item 'More episodes' that allows you to browse to all 
  episodes of the same programme.
- Continue Listening with two-way sync.
- Search with saved search terms.
- Convenient account sign-in.  
  Sign in with your email address and password, or let the BBC email you a 
  link to sign in.


Visit [dimkroon.net](https://dimkroon.net/en/pages/addon-bbcsounds.html) for 
more details and installation instructions.


## Issues
I'm very interested in any issues that you might find. Please open an issue 
here on GitHub, or post a message on 
the [support thread in the Kodi forum](https://forum.kodi.tv/showthread.php?tid=388288).

Please include an accurate description of the problem. Describe 
exactly what steps to make to reproduce the problem (every click from the 
home menu). And always attach a link to a 
[debug log file](https://kodi.wiki/view/Log_file).
